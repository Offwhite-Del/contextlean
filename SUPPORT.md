# Support / 获取帮助

For reproducible defects, use the [bug report form](https://github.com/Offwhite-Del/contextlean/issues/new?template=bug_report.yml). For bounded feature proposals, use the [feature request form](https://github.com/Offwhite-Del/contextlean/issues/new?template=feature_request.yml).

可复现的缺陷请使用[缺陷报告表单](https://github.com/Offwhite-Del/contextlean/issues/new?template=bug_report.yml)；范围明确的功能建议请使用[功能建议表单](https://github.com/Offwhite-Del/contextlean/issues/new?template=feature_request.yml)。

Do not publish credentials, private paths, configuration values, Agent transcripts, plans, backups, or receipts. Security vulnerabilities must be reported privately through [GitHub Security Advisories](https://github.com/Offwhite-Del/contextlean/security/advisories/new).

不要公开凭证、私人路径、配置值、Agent 会话、计划、备份或回执。安全漏洞必须通过 [GitHub Security Advisories](https://github.com/Offwhite-Del/contextlean/security/advisories/new) 私下报告。
