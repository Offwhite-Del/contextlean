# Code of Conduct / 行为准则

## Our standard / 我们的标准

Be respectful, specific, and evidence-oriented. Welcome people regardless of background or experience. Critique ideas and implementations, not people. Do not publish another person's private data, credentials, configuration, or Agent transcripts.

请保持尊重、具体并以证据为依据；平等对待不同背景与经验的人。讨论观点和实现，不攻击个人。不得公开他人的私人数据、凭证、配置或 Agent 会话。

## Unacceptable behavior / 不可接受的行为

Harassment, threats, discrimination, deliberate disruption, sexualized attention, and disclosure of private information are not tolerated in project spaces or when representing the project.

项目空间及代表项目的场合不接受骚扰、威胁、歧视、蓄意干扰、性化关注或泄露私人信息。

## Enforcement / 执行

Report conduct concerns privately through the maintainer contact available on the repository owner's GitHub profile. Include links or screenshots, but remove unrelated private information. Maintainers may edit, remove, or reject contributions and may temporarily or permanently restrict participation when necessary.

请通过仓库所有者 GitHub 主页上的维护者联系方式私下报告行为问题。可附链接或截图，但应删除无关私人信息。维护者可在必要时编辑、移除或拒绝内容，并临时或永久限制参与。
